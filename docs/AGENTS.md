# docs 协作约定

继承项目根 [AGENTS.md](../AGENTS.md)，先读 [README.md](README.md)。

- 用户要求、技术判断、真实验证结果与待验项明确分开；用户后续改变范围时同步 PROJECT、README 与相关入口。
- `VERIFICATION.md` 保存可公开的验证摘要。`verification/` 内 JSON 与图片为本机原件并被 Git 忽略，不为美化结果或路径变化修改历史记录；新增运行写新文件，标采样日期、范围和局限。
- 静态图不证明菜单点击通过，短时无界面资源采样不代表完整 GUI 或长期功耗。迁移校验不代替功能验收。
- 公开文档使用仓库相对路径，不链接被忽略的原件、私有知识库或本机迁移位置。迁移记录可本机保存但不上传；公开文档不引用用户私密对话。
