## 1. 点子、情绪词、氛围决定

### 1.1 点子

面板是一张体检单。标题先说结论。有问题的项目被划出来，正常的项目只打勾。

换题检查：换成猫、汽车或天气，这句话不成立。它把 Mac 当作需要体检的身体，不引入第二套隐喻。点子只是语义，不改名，不做纸张皮肤。项目名仍是 CPU、内存、磁盘、网络、电池、温度。

### 1.2 情绪词与可观察量

| 词 | 可观察量 | 检查方式 |
|---|---|---|
| 安心 | 全绿面板高度 ≤290 pt。全绿时 17 pt 字只出现在标题块里。全绿截图中非灰像素 ≤2% | 预览截图加 UI 测试 |
| 划出来 | 只有问题行有底色、曲线、17 pt 数值和「已持续」。正常行一行 13 pt | 预览截图 |
| 轻 | 容器圆角只有 8 pt 与全圆。主列没有分隔线，只用间距。侧栏图表一图一线。面板里没有持续动画，没有位图素材 | 源码审计加截图 |

### 1.3 氛围决定

| 维度 | 决定 | 理由 |

| 材质 | 不加。只保留窗口的 `.popover` 系统材质 | 再铺纸纹是第二种材质，且压在正文下面 |

| 光 | 状态光只在深色外观出现：标题块背后一块预渲染的顶部径向渐变，宽 352 pt，高 96 pt。黄级 `dot.warning` 10%，红级 `dot.danger` 16%。正常没有光。状态变化时 400 ms 交叉淡变。浅色外观没有状态光 | 光承载状态含义，不是装饰渐变。浅色截图里光是一团没有形状的粉色（X15），因此浅色删除（Fable 第 1 轮第 3 条，理由见 docs/CI.md） |

## 2. 令牌变更

### 2.1 字号

| 令牌 | 值 | 用途 |
|---|---|---|
| `type.lead` | 17 pt semibold | 标题块，问题行数值，侧栏标题 |
| `type.body` | 13 pt medium 或 regular | 名称，正常行，按钮 |
| `type.note` | 11 pt regular | 注释，说明 |
| `type.axis` | 10 pt regular，等宽数字 | 仅侧栏坐标轴 |

删除旧令牌 `display`（28）、`title`（20）、`callout`（12），以及它们的全部引用。一屏最多 4 档。

### 2.2 圆角

只有 `radius.control = 8` 与 `radius.full`。把现有 6、4、3 并入 8 或全圆。状态点、进度条端点用全圆。

### 2.3 颜色

1. 强调色 `accent` 只在 3 处出现：有问题时的实心主按钮，键盘焦点环，文字链接的悬停态不用。
2. 删除 `fill.selected` 的蓝色。侧栏打开时对应行的背景用 `fill.hover` 加深一档（黑 10%，白 14%）。
3. 分段控件选中项用 `fill.hover` 加深一档，文字 `text.primary`，不用蓝字。
4. 「进行中」不用颜色表示，用虚线圆点形状（空心虚线，8 pt）。
5. 内存堆叠条用中性色单条：已用 `chart.line` 55%，可用 `chart.fill`。
6. 其余令牌沿用 DESIGN_V2.md 3.3。

## 4. 标题块与菜单栏图标

### 4.1 标题块（取代 DESIGN_V2.md 第 4 章英雄区）

1. 面板没有比熊，没有气泡，没有道具，没有舞台。删除位图序列帧、位图静帧、比熊图库和它们的门禁（U10）。
2. 标题块是一句话：`type.lead`，左对齐，最多 2 行，不换行拆词。块高固定 64 pt。文字左右内边距 16 pt。
3. 这句话是面板唯一的标题。它沿用 `Core/BubbleCopy.swift` 的模板与口吻（「磁盘 5 天胖了 314 GB，该让 Agent 看看了」）。文案宽度预算按 17 pt 与 320 pt 内容宽重算，每行上限写进单测。
4. 句中的数字不单独着色（X13）。等级由下面的问题行表达。
5. 状态光见 1.3。
6. 采集中：标题写「正在检查，已完成 N/6 项」，N 随采样器报到递增。超过 0.5 s 仍无数据才出现。其余时间标题直接显示结果。

### 4.2 菜单栏图标：静态与奔跑

用户要用简单的帧动画体现系统状态（U10）。图标只有两种姿态：静态和奔跑。形象是侧视的比熊剪影。参照做法是 RunCat：静止，或循环奔跑，速度表示忙碌程度。

| 项目 | 规则 |
|---|---|
| 画布 | 24 × 18 pt，与现有状态项同宽，状态项宽度永远不变 |
| 形象 | 侧视比熊剪影：圆头、卷毛团身体、翘起的尾球、4 条短腿。矢量绘制（`Path`），不使用位图。身体用按钮外观的墨色（`labelColor`），不是模板图 |
| 静态 | 站立一帧。一切正常且 CPU 不忙时使用 |
| 奔跑 | 4 帧循环：腿前伸、腿收拢、腿后蹬、腾空。身体上下起伏 ≤1 pt。所有帧同一画布尺寸 |
| 何时奔跑 | CPU 忙时。取引擎最近一次采样的整机 CPU 利用率。≥35% 开始奔跑。降到 <25% 且连续 2 个 tick（60 s）后回到静态（迟滞，避免抖动） |
| 速度 | 35% 到 60%：4 fps。60% 到 85%：6 fps。≥85%：8 fps。只有这三档 |
| 健康标记 | 沿用 v2：留意 = 黄色 ▲，异常 = 红色 ■，画在图标右下角，形状加颜色。标记与姿态互不影响，奔跑时标记不动 |
| 采集中、过期 | 静态，空心轮廓加原有标记（采集中、过期）。不奔跑 |
| 动效退路 | Reduce Motion、屏幕锁定、显示器睡眠、图标被隐藏、低电量模式：回到静态，计时器停止 |
| 计时器 | 只在奔跑时存在一个 `Timer`，间隔等于帧间隔，`tolerance` 为间隔的 20%。停止奔跑时立即 `invalidate`。帧图按「姿态、标记、深浅」缓存，懒生成 |
| VoiceOver 与提示 | 沿用 v2 文案。奔跑时在末尾加「，CPU 占用高」（文字以句号结尾时，加在句号前） |
| 标记位置 | 右下角 6.5 × 6.5 pt 方框（x 17.5，y 11.5），外加 0.75 pt 透明间隙。比熊的任何一帧都不进入这个方框 |

> **注意**：奔跑动画需要面板关闭时存在一个低频计时器。这与 AGENTS.md 现有的「状态卡关闭时只维持 30 秒 tick」冲突。用户明确要求这个动画（U10），因此改写 AGENTS.md：关闭面板时允许一个 ≤8 Hz 的图标计时器，只在奔跑时存在，CPU 不忙时不存在。门禁 W16 同步改为「CPU 不忙时 0 个图标计时器」。

菜单栏图标不再有 v2 的姿态切换动画（≤8 帧、490 ms）和耳朵、舌头、空心等姿态。健康状态只由形状标记表达。

## 5. 分项区与底部

### 5.1 问题行

| 元素 | 规则 |
|---|---|
| 第 1 行 | 左：形状点加名称（`type.body`）。右：数值（`type.lead`，等宽数字，`text.primary`），右缘距内容边 16 pt。数值前不加前缀词。等级只由形状、底色、曲线表达 |
| 第 2 行 | `type.note`。格式：「人话原因，已持续 N」。例：「5 天胖了 314 GB，已持续 3 小时」 |
| 曲线 | 在底色内部，文字下方：x 16 至 320，y 46 至 62（距底边 10 pt），高 16 pt。按本行自己的最小值与最大值归一化（`SparkFit`，最小跨度为固定量程的 2%），振幅 ≥12 pt。线宽 1.5 pt，等级色。面积填充从线下 14% 渐变到曲线带底边 0%，底色里没有硬边方块。最右端一个实心点，距右缘 18 pt |
| 底色 | 同一等级同一底色，所有问题行都有，圆角 8 pt，宽 336 pt |
| 已持续 | 每分钟加 1，用 `.numericText` 翻一位 |

人话原因用标题块同一套口吻，只用在问题行：磁盘「胖了」，内存「喘不过气」，电池「掉电太快」，CPU「跑太久」，温度「发烫」。数字必须保留，口吻不替代数字。每条文案 ≤24 宽度单位，Core 单测检查。

### 5.2 正常行

形状点加名称加数值，一行，`type.body`，`text.secondary`，数值 `text.primary`。✓ 用 SF Symbols `checkmark`，9 pt，`text.tertiary`。网络没有等级，用 6 pt `dot.neutral` 圆点，不用 ✓。没有曲线。每行点击区 ≥24 pt 高。悬停与点击行为沿用 DESIGN_V2.md 5.6。

### 5.3 记录行

删除「异常 N 项，最久已持续 3 小时」。所有状态只留「近 7 天 N 条记录 ›」，靠左，文字与标题同一 x（16 pt），`type.note`，`text.secondary`，悬停变 `text.primary`。全绿时不写「✓ 没有异常」（与标题重复）。采集中为空。

### 5.4 底部按钮

| 状态 | 样式 | 文字 |
|---|---|---|
| 有问题 | 实心 `accent.fill`，高 32 pt，圆角 8 pt，宽满主列减「···」按钮 | 「复制排查提示词」，一行，没有副文字 |
| 无问题 | 文字按钮，`text.primary`，悬停 `fill.hover` | 「复制日常巡检提示词」 |
| 采集中 | 隐藏，不禁用 | 无 |

「···」改为无底色的图标按钮（32×32 pt），悬停 `fill.hover`，用 SF Symbols `ellipsis`，加 `accessibilityLabel`「更多」。

### 5.5 采集中

1. 面板打开后，超过 0.5 s 仍无数据，才显示采集中状态。
2. 标题块写「正在检查，已完成 N/6 项」，N 随采样器报到递增。
3. 六个正常行样式的行，数值位置写「—」。数据到达的行立即换成数值。
4. 不写「正在采集」。

### 5.6 签名时刻：爪印章

触发：用户点击主按钮或按 ⌘C，且写入剪贴板成功。

| 步骤 | 时间 | 内容 |
|---|---|---|
| 1 | 0 ms | 按钮文字淡出。爪印章带「已复制」从 1.25 倍缩到 1.0，落在按钮中央，用「到达」令牌 |
| 2 | 1500 ms | 印章淡出 200 ms，按钮文字淡入 |

按钮外框不变，布局不抖。写入失败时沿用 DESIGN_V2.md 8.1 第 4 条，不出印章。爪印用 `GlyphPaths.swift` 的矢量路径，没有时新增一个。Reduce Motion 时印章直接出现，无缩放。爪印只在这 1 处出现。

## 8. 性能预算

删除比熊序列帧（U10）使面板打开期间的成本大幅下降。U9 放宽的额度保留，不使用。

| 指标 | v2 | v3 | 理由 |
|---|---|---|---|
| 面板关闭，CPU 不忙（W16） | 0 个 CA 动画，0 字节精灵，1 个计时器 | 0 个 CA 动画，1 个计时器（引擎 tick），0 个图标计时器 | 极其轻量 |
| 面板关闭，CPU 忙 | — | 多 1 个图标计时器，≤8 Hz，平均 CPU <1%（真机） | U10 |
| 面板打开 60 s 进程 CPU 均值 | ≤3% | ≤3%（不变） | 面板里没有持续动效 |
| 点击到首帧（W03） | ≤150 ms | 不变 | 打开速度不放宽 |
| 精灵内存、精灵帧率（W18 等） | ≤8 MB，18 fps | 删除（没有精灵） | U10 |
| 包体 | — | 减少约 2.9 MB（`Resources/DogSprites` 2.5 MB 加 `DogArt` 0.4 MB） | U10 |
| 禁止 | — | 实时 backdrop 模糊，`TimelineView`，`CADisplayLink`，面板里的持续动画 | 状态光是预渲染图，不是实时模糊 |

> **注意**：改动门禁阈值必须在 `docs/CI.md` 写新条目，写明用户原话 U9 或 U10 与新旧数值。不得悄悄放宽。
