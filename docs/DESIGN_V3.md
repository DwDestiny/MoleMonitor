## 1. 点子、情绪词、氛围决定

### 1.1 点子

面板是比熊递给你的一张体检单。比熊先说结论。有问题的项目被划出来，正常的项目只打勾。

换题检查：换成猫、汽车或天气，这句话不成立。它延续 DESIGN_V2.md 4.1「比熊的身体就是这台电脑」，不是第二套隐喻。点子只是语义，不改名，不做纸张皮肤。项目名仍是 CPU、内存、磁盘、网络、电池、温度。

### 1.2 情绪词与可观察量

| 词 | 可观察量 | 检查方式 |
|---|---|---|
| 安心 | 全绿面板高度 ≤340 pt。全绿时 17 pt 字只出现在气泡里。全绿截图中非灰像素 ≤2%，比熊除外 | 预览截图加 UI 测试 |
| 划出来 | 只有问题行有底色、曲线、17 pt 数值和「已持续」。正常行一行 13 pt | 预览截图 |
| 轻 | 容器圆角只有 8 pt 与全圆。主列没有分隔线，只用间距。侧栏图表一图一线 | 源码审计加截图 |

### 1.3 氛围决定

| 维度 | 决定 | 理由 |
|---|---|---|
| 材质 | 不加。只保留窗口的 `.popover` 系统材质 | 再铺纸纹是第二种材质，且压在正文下面 |
| 质感层 | 比熊压在列表上边缘 6 pt（前后层），脚下保留软阴影 | why-good 第 7 节「层叠」 |
| 光 | 状态光：比熊身后一个预渲染的椭圆径向渐变 240×120 pt。黄级 `dot.warning` 10%，红级 `dot.danger` 12%（深色 16%）。正常没有光。状态变化时 400 ms 交叉淡变 | 光承载状态含义，不是装饰渐变。截图看是否像洗色，像则删 |
| 语汇 | 形状点（✓、▲、■）、整行等级底色、英雄区道具。三类元素用在主列、侧栏、异常记录 | 体检单的勾、划线、物件。不增加新隐喻 |
| 边角 | 8 pt 与全圆。窗口 12 pt 由系统给 | D4 |
| 动效气质 | 呼吸加一个主角。主角是比熊，持续动效，占屏约 12%。其余只有反馈动效。U6 原话指定比熊动画，超出「呼吸」的 ≤10% 上限，已写明 | restraint 第 3 节 |
| 签名时刻 | 全页 1 处：复制成功，爪印章落定（见 5.6） | restraint 第 1 节 |

## 2. 令牌变更

### 2.1 字号

| 令牌 | 值 | 用途 |
|---|---|---|
| `type.lead` | 17 pt semibold | 气泡正文，问题行数值，侧栏标题 |
| `type.body` | 13 pt medium 或 regular | 名称，正常行，按钮 |
| `type.note` | 11 pt regular | 注释，说明 |
| `type.axis` | 10 pt regular，等宽数字 | 仅侧栏坐标轴 |

删除旧令牌 `display`（28）、`title`（20）、`callout`（12），以及它们的全部引用。一屏最多 4 档。

### 2.2 圆角

只有 `radius.control = 8` 与 `radius.full`。把现有 6、4、3 并入 8 或全圆。状态点、进度条端点用全圆。

### 2.3 颜色

1. 强调色 `accent` 只在 3 处出现：有问题时的实心主按钮，键盘焦点环，文字链接的悬停态不用。
2. 删除 `fill.selected` 的蓝色。侧栏打开时对应行的背景用 `fill.hover` 加深一档（黑 10%，白 14%）。
3. 分段控件选中项用 `fill.hover` 加深一档，文字 `text.primary`，不用蓝字。
4. 「进行中」不用颜色表示，用虚线圆点形状（空心虚线，8 pt）。
5. 内存堆叠条用中性色单条：已用 `chart.line` 55%，可用 `chart.fill`。
6. 其余令牌沿用 DESIGN_V2.md 3.3。

## 4. 英雄区

1. 删除舞台方块、渐变、竖纹、虚线地面。比熊直接站在面板材质上。
2. 比熊定位：每个精灵定义 `baseline` 常量。比熊脚底线锚定到列表上边缘这个固定 y，压入 6 pt。行重排时比熊不跳。
3. 脚下保留软阴影：y 2 pt、模糊 6 pt、黑 10%。浅色模式下白比熊压在浅底上，只靠这层阴影分出前后。
4. 气泡：`type.lead`，圆角 8 pt。尾巴指向比熊头部，距头 ≤8 pt。气泡是面板唯一的标题。
5. 全绿时比熊趴下，宽度比站姿大。列表上边留 8 pt 内缩，其余不变。
6. 道具（纸箱堆等）保留，与比熊同一地面线。DESIGN_V2.md 1.2 里「饭盆」的措辞改成「箱子堆」。
7. 状态光见 1.3。

## 5. 分项区与底部

### 5.1 问题行

| 元素 | 规则 |
|---|---|
| 第 1 行 | 左：形状点加名称（`type.body`）。右：数值（`type.lead`，等宽数字），右缘距内容边 16 pt。数值前不加前缀词 |
| 第 2 行 | `type.note`。格式：「人话原因，已持续 N」。例：「5 天胖了 314 GB，已持续 3 小时」 |
| 曲线 | 行底，整行宽，高 16 pt。线宽 1.5 pt，等级色。面积填充 10%。最右端一个实心点 |
| 底色 | 同一等级同一底色，所有问题行都有，圆角 8 pt，宽 336 pt |
| 已持续 | 每分钟加 1，用 `.numericText` 翻一位 |

人话原因用气泡同一套口吻，只用在问题行：磁盘「胖了」，内存「喘不过气」，电池「掉电太快」，CPU「跑太久」，温度「发烫」。数字必须保留，口吻不替代数字。每条文案 ≤24 宽度单位，Core 单测检查。

### 5.2 正常行

形状点加名称加数值，一行，`type.body`，`text.secondary`，数值 `text.primary`。✓ 用 SF Symbols `checkmark`，9 pt，`text.tertiary`。网络没有等级，用 6 pt `dot.neutral` 圆点，不用 ✓。没有曲线。每行点击区 ≥24 pt 高。悬停与点击行为沿用 DESIGN_V2.md 5.6。

### 5.3 记录行

删除「异常 N 项，最久已持续 3 小时」。有问题时只留「近 7 天 N 条记录 ›」，`type.note`，`text.secondary`，悬停变 `text.primary`。全绿时左侧写「✓ 没有异常」，右侧写同一入口。

### 5.4 底部按钮

| 状态 | 样式 | 文字 |
|---|---|---|
| 有问题 | 实心 `accent.fill`，高 32 pt，圆角 8 pt，宽满主列减「···」按钮 | 「复制排查提示词」，一行，没有副文字 |
| 无问题 | 文字按钮，`text.primary`，悬停 `fill.hover` | 「复制日常巡检提示词」 |
| 采集中 | 隐藏，不禁用 | 无 |

「···」改为无底色的图标按钮（32×32 pt），悬停 `fill.hover`，用 SF Symbols `ellipsis`，加 `accessibilityLabel`「更多」。

### 5.5 采集中

1. 面板打开后，超过 0.5 s 仍无数据，才显示采集中状态。
2. 比熊做 `sniff`。气泡写「闻到 N/6 项」，N 随采样器报到递增。
3. 六个正常行样式的行，数值位置写「—」。数据到达的行立即换成数值。
4. 不写「正在采集」。

### 5.6 签名时刻：爪印章

触发：用户点击主按钮或按 ⌘C，且写入剪贴板成功。

| 步骤 | 时间 | 内容 |
|---|---|---|
| 1 | 0 ms | 按钮文字淡出。爪印章带「已复制」从 1.25 倍缩到 1.0，落在按钮中央，用「到达」令牌 |
| 2 | 60 ms | 比熊做既有动作 `wag` |
| 3 | 1500 ms | 印章淡出 200 ms，按钮文字淡入 |

按钮外框不变，布局不抖。写入失败时沿用 DESIGN_V2.md 8.1 第 4 条，不出印章。爪印用 `GlyphPaths.swift` 的矢量路径，没有时新增一个。Reduce Motion 时印章直接出现，无缩放，比熊不动。爪印只在这 1 处出现。

## 7. 动效令牌

| 令牌 | 刚度 / 阻尼 / 质量 | 用途 |
|---|---|---|
| `motion.feedback` | 380 / 30 / 0.5 | 悬停、按下、数字翻动 |
| `motion.move` | 200 / 28 / 0.9 | 侧栏、行重排、高度、淡入上移 |
| `motion.arrive` | 320 / 24 / 0.7，过冲 ≤2% | 爪印章、气泡弹出 |
| `motion.fade` | 160 ms easeInOut | Reduce Motion 下所有尺寸与位移动画的替代 |

不同物体错开 20 到 80 ms。同一物体的部件同起同止。无限循环动画只有比熊 1 个。

## 8. 性能预算（U9 放宽）

U1「极其轻量」仍然成立。关闭面板后的零成本不放宽。只放宽面板打开期间。

| 指标 | v2 | v3 | 理由 |
|---|---|---|---|
| 面板关闭后（W16） | 0 个 CA 动画，0 字节精灵，CPU <5% | 不变 | 极其轻量 |
| 面板打开 60 s 进程 CPU 均值 | ≤3% | ≤8%（Apple Silicon 真机） | 比熊帧率提高，状态光交叉淡变，行级动画 |
| CI 稳态 CPU（W17，10 s） | ≤3% | ≤10% | VM 软件渲染余量 |
| 比熊帧率上限 | 18 fps | 24 fps | 动作更流畅 |
| 精灵内存（W18） | ≤8 MB | ≤16 MB | 缓存当前加预取动作的完整条带 |
| 点击到首帧（W03） | ≤150 ms | 不变 | 打开速度不放宽 |
