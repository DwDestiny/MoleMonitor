# Sources 协作约定

继承项目根 [AGENTS.md](../AGENTS.md)，先读本目录 [README.md](README.md)。

- `MoleMonitor.swift` 管理只读 UI、NDJSON 适配、应用归并与采集进程；`Sensors.swift` 管理只读系统和 SMC 采样。跨模块变更同步更新对应说明和文件头。
- 保持后台采集、主线程界面；无界面入口不能创建状态栏或可见窗口。
- 未知/失败值保持可选值，不能补成零；保持温度均值、CPU 单核与 RSS 口径提示。
- 传感器只能读键；不写 SMC，不提权，不控制风扇。应用排行只取可执行名称，不读取完整进程参数。
- 修改后先构建和协议检查；根据改动补实际采样或异常恢复验证。原件可新增到 Git 忽略的 `docs/verification/`，不覆盖基线；公开提交只更新脱敏摘要。
